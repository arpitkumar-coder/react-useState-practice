- Updating state using setter functions

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/arpitkumar-coder/react-useState-practice.git
```

2. Open the project folder:

```bash
cd react-useState-practice
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```
